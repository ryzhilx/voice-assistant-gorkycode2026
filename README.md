# Голосовой ассистент для задач и встреч

[![Build Status](https://github.com/ryzhilx/voice-assistant-gorkycode2026/actions/workflows/ci.yml/badge.svg?branch=main)](https://github.com/ryzhilx/voice-assistant-gorkycode2026/actions/workflows/ci.yml)

Telegram-бот с поддержкой голосового и текстового управления личными задачами, встречами и напоминаниями на естественном языке.

## Быстрый запуск

### 1. Настройка окружения

Создайте файл `.env` на основе примера:
```bash
cp .env.example .env
```

Заполните переменные:
```ini
TELEGRAM_BOT_TOKEN=ваш_токен_бота
YANDEX_API_KEY=ваш_api_ключ_yandex_cloud
YANDEX_FOLDER_ID=ваш_folder_id_yandex_cloud
APP_TIMEZONE=Europe/Moscow
DATABASE_PATH=assistant.db
```

### 2. Запуск через Docker

```bash
docker compose up -d --build
```

### 3. Локальный запуск

1. Установите зависимости:
```bash
python -m venv venv
# Linux/macOS:
source venv/bin/activate
# Windows:
.\venv\Scripts\activate

pip install -r requirements.txt
```

2. Запустите бота:
```bash
python -m app.bot.main
```

## Запуск тестов

```bash
python -m unittest discover -s tests
```

## Архитектура и технологии

Бот разделен на несколько понятных модулей:

- Бот и интерфейс: aiogram 3 на Python 3.12. Принимает текст и голосовые сообщения в Telegram.
- Голос: Yandex SpeechKit. Переводит голос в текст (STT) и озвучивает ответы (TTS).
- Логика и диалог: оркестратор держит контекст (например, фразу «перенеси ее на завтра»), умеет переспрашивать время, если его не указали, и предупреждает о накладках во встречах.
- Понимание текста: YandexGPT разбирает запрос в JSON. Если API временно недоступен, управление перехватывает локальный парсер на регулярках и правилах, поэтому бот отвечает всегда.
- Поиск: ищет задачи не только по точным словам, но и по смыслу — через эмбеддинги Яндекса и локальный словарь синонимов со стеммингом («договор» найдет «контракт»).
- База данных: SQLite в режиме WAL. Легкая, без внешних демонов, данные пользователей изолированы по chat_id.

## Что решили сделать сами

- Двойной контур NLU: если YandexGPT тормозит или не отвечает, запрос мгновенно подхватывает локальный парсер на правилах. Пользователь никогда не увидит ошибку сервера.
- Составные команды (Multi-Action): бот умеет разбирать сложные фразы из нескольких действий за раз («Поставь встречу с Михаилом в 14:00 и напомни купить кофе в 18:00»).
- Умный семантический поиск: совмещен поиск по векторным эмбеддингам и локальный стемминг со словарем синонимов.
- Voice UX: на голосовые бот отвечает голосом и дублирует текст, на текстовые сообщения — только текстом, чтобы не шуметь.
- Пул соединений: запросы в Yandex Cloud идут через постоянный HTTP-клиент (Keep-Alive), что экономит до полусекунды на каждом ответе.
- Хранилище данных: SQLite в режиме WAL обеспечивает надежность транзакций и быстрый отклик без необходимости поднимать отдельный сервер СУБД.
