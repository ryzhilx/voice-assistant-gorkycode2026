Интеллектуальный Telegram-бот с голосовым и текстовым интерфейсом для управления личными задачами, встречами и напоминаниями на естественном языке, построенный на современной агентной архитектуре с нативным **Function / Tool Calling**.

---

## Ключевые возможности

- **Voice-First UX:** 
  - Распознавание голосовых заметок (STT) и синтез естественной речи (TTS) через Yandex SpeechKit.
  - Адаптивный ответ: на голосовое сообщение бот отвечает голосом и текстом, на текстовое — только текстом.
- **Агентная архитектура (Native Tool Calling):**
  - Работает на базе Function Calling API YandexGPT с декларативной JSON-схемой инструментов.
  - Понимание контекста диалога и ведение естественной беседы.
  - **Multi-Action:** выполнение сразу нескольких действий из одного составного сообщения (*«Поставь встречу с Михаилом завтра в 14:00 и напомни купить кофе в 18:00»*).
- **Управление встречами и задачами:**
  - Создание задач и напоминаний с распознаванием относительного и точного времени (*«завтра в 10 утра»*, *«через 20 минут»*).
  - Создание встреч с проверкой накладок (коллизий) в расписании.
  - Оперативный перенос и контекстные корректировки (*«перенеси ее на 15:00»*, *«а нет, давай лучше через 10 минут»*).
  - Отметка о выполнении в прошедшем времени (*«я выпил таблетку»*, *«сделал отчет»*).
  - Переименование и отмена записей.
- **Периодические события (Recurrence):**
  - Поддержка правил повторения: ежедневно (`daily`), по будням (`weekdays`), по выходным (`weekends`), по дням недели (`weekly:mon`...`weekly:sun`), еженедельно (`weekly`), ежемесячно (`monthly`).
  - Автоматическое вычисление следующей даты при выполнении регулярной задачи.
  - Детекция конфликтов с учетом периодических встреч.
- **Гибридный семантический поиск:**
  - Комбинация векторных эмбеддингов Yandex Cloud (`text-search-query` / `text-search-doc`) и локального морфологического стемминга с синонимами (запрос *«договор»* находит *«контракт»*).
- **Фоновые напоминания и часовые пояса:**
  - Асинхронный воркер напоминаний проверяет дедлайны каждую минуту.
  - Поддержка индивидуального часового пояса пользователя (`/timezone` — выбор из популярных городов или отправка геолокации).
- **Архив и расписание:**
  - Просмотр расписания на день, неделю или произвольный период.
  - Архив завершенных задач и прошедших встреч.

## Быстрый старт

### 1. Настройка окружения

Скопируйте пример файла конфигурации:
```bash
cp .env.example .env
```

Заполните переменные в `.env`:
```ini
TELEGRAM_BOT_TOKEN=
YANDEX_API_KEY=
YANDEX_FOLDER_ID=
APP_TIMEZONE=Europe/Moscow
DATABASE_PATH=assistant.db
```

> **Примечание:** Для работы распознавания и синтеза речи аккаунту Yandex Cloud требуется роль `ai.speechkit-stt.user` и `ai.speechkit-tts.user`. Для генерации ответов и эмбеддингов — `ai.languageModels.user`.

### 2. Запуск через Docker (рекомендуется)

```bash
docker compose up -d --build
```

### 3. Локальный запуск

1. Убедитесь, что установлен Python 3.12+ и утилита `ffmpeg` (необходима для работы с аудиоформатами).
2. Создайте и активируйте виртуальное окружение:
   ```bash
   # Linux/macOS:
   python3.12 -m venv venv
   source venv/bin/activate

   # Windows:
   py -3.12 -m venv venv
   .\venv\Scripts\activate
   ```
3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
4. Запустите приложение:
   ```bash
   python -m app.bot.main
   ```

## Примеры команд и сценариев

| Сценарий | Пример реплики пользователя |
| :--- | :--- |
| **Создание задачи** | *«Напомни мне завтра в 10 утра позвонить в банк»* |
| **Создание регулярной задачи** | *«Каждый день в 9:00 пить витамины»* |
| **Создание встречи** | *«Поставь встречу с Кириллом во вторник в 15:30»* |
| **Уточняющий диалог** | Пост: *«Поставь созвон с дизайнером»* → Бот: *«На какую дату и время поставить созвон?»* |
| **Оперативный перенос** | *«А нет, давай через 15 минут лучше»* или *«Перенеси встречу на завтра на 16:00»* |
| **Отметка о выполнении** | *«Я выпил витамины»* или *«Отчет отправлен»* |
| **Составные команды** | *«Поставь встречу с инвестором в 14:00 и напомни купить цветы в 18:00»* |
| **Поиск по смыслу** | *«Найди задачу про договор»* (найдёт задачу *«Согласовать контракт»*) |
| **Расписание и архив** | *«Что у меня запланировано на эту неделю?»*, *«Покажи архив»* |
